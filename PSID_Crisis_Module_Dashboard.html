How To Read The Ranking

The dashboard scores each item by information value relative to respondent burden so the retained module stays compact but analytically useful.

Priority score

Rᵢ = Uᵢ / Bᵢ

Rᵢ is the main ranking signal. Higher values mean the item returns more useful crisis information per unit of burden.

Utility

Uᵢ = Σ weighted signals

Uᵢ rises when a question captures stronger crisis constructs such as hardship, trauma, displacement, aid, or employment disruption.

Burden

Bᵢ = length + complexity

Bᵢ increases for longer wording or more complex prompts. Lower burden helps short high-value items surface to the top.
